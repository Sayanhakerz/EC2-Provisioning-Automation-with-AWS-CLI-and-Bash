AWS EC2 Instance Creation Using Shell Scripting

Project Overview

This project demonstrates how to automate the creation of an AWS EC2 instance using a Bash shell script and the AWS CLI.

Technologies Used

- AWS EC2
- AWS CLI
- Bash Shell Scripting
- Linux

Features

- Automates EC2 instance creation.
- Waits until the instance reaches the running state.
- Displays the instance ID.
- Confirms successful instance creation.

Execution

The script was executed successfully, and the EC2 instance reached the running state.
